# CTM-nSeq crRNAfindR package

The CTM-nSeq crRNAfindR package contains the main CTM_crRNAfindR function, which can be used to find sets of crRNAs matching given parameters for specificity and efficiency (using BLAST, RNAfold, CRISPOR). In addition, overhangs generated by crRNAs can be compared and sets with optimal crRNA pairs for all loci will be returned.

## Input

The input has to be an excel file containing genomic regions for each target in a "bed"-style format. Ideally the file contains the following columns: 
	"Assoc_locus": locus (or name)
	"Chr": chromosome in genome on chromosome
	"start": start of target region on chromosome
	"end": end of target region
	"strand": feature strand (+/-)
	"window": size of window on either side of target region to search crRNAs in
	"feature": name of feature (add ROI for region of interest)
